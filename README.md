# Portfolio — Faveur Morak

Portfolio professionnel de **Faveur Morak**, consultante en communication digitale, community manager et créatrice de contenus basée à Abidjan, Côte d'Ivoire.

## 🚀 Aperçu

- **Domaines :** Communication digitale, Stratégie social media, Tournage & Montage, Storytelling, Community Management
- **Localisation :** Abidjan, Côte d'Ivoire
- **Design & UI :** Palette soignée (bordeaux `#5c0f1e` & crème `#fffcf9`), typographie élégante, animations fluides, responsive mobile & desktop

## 🛠 Technologies

- HTML5 sémantique & accessible
- Vanilla CSS moderne (CSS Variables, Flexbox, CSS Grid, animations fluides)
- JavaScript moderne (IntersectionObserver, micro-interactions, responsive lightbox)
- Déploiement optimisé pour **Vercel**

## 🌐 Déploiement sur Vercel

1. Connectez-vous sur [Vercel](https://vercel.com).
2. Cliquez sur **Add New...** > **Project**.
3. Importez le dépôt GitHub `faveurmorak`.
4. Laissez les réglages par défaut (détection automatique en site statique).
5. Cliquez sur **Deploy**. Le site est en ligne en quelques secondes !
